# AS-Agency Desktop — инструкция запуска

Это первый desktop-порт текущей локальной платформы InstaWorm/Instalead. Существующие React-интерфейс и Node.js backend сохранены; Electron открывает их в отдельном окне. Данные новой desktop-установки хранятся отдельно в папке приложения пользователя.

## Важно перед запуском

- Нужен Node.js 20 LTS или новее и npm.
- Не переносите в этот архив старый `backend/.env`, базы данных, cookies или сессии: они намеренно исключены из сборки.
- Не публикуйте `.env`, API-ключи и базы данных.
- Desktop-оболочка сама по себе не делает Instagram-автоматизацию безопасной и не добавляет официальную поддержку Meta API. Не используйте приватные endpoints, обходы ограничений или массовые нежелательные сообщения. Для реальной отправки используйте только разрешённые Meta механизмы и соблюдайте правила платформы.

## Запуск на Windows (режим разработки)

1. Распакуйте архив в обычную папку, например `C:\AS-Agency-Desktop`.
2. Установите Node.js LTS с https://nodejs.org/ (если ещё не установлен).
3. Откройте папку проекта в Проводнике.
4. В адресной строке папки напишите `cmd` и нажмите Enter.
5. Выполните:

   ```bat
   npm run setup
   npm run dev
   ```

6. Откроется окно AS-Agency Desktop. При первом запуске установка зависимостей может занять несколько минут.
7. Для остановки закройте Electron-окно и окна терминалов.

## Сборка установщика Windows

В терминале из корня проекта:

```bat
npm run setup
npm run dist:win
```

Готовый установщик появится в папке `release`. Сборку Windows лучше выполнять непосредственно на Windows.

## macOS / Linux

После `npm run setup` используйте `npm run dist:mac` или `npm run dist:linux` на соответствующей операционной системе.

## Где хранятся данные

Desktop-версия использует отдельную папку данных Electron:

- Windows: `%APPDATA%/as-agency-desktop/data`
- macOS: `~/Library/Application Support/as-agency-desktop/data`
- Linux: `~/.config/as-agency-desktop/data`

Сделайте резервную копию этой папки перед обновлениями. Исходные базы из присланного архива в этот пакет не включены.

## Проверка

После запуска локальный backend доступен на `http://127.0.0.1:3002/health`. Не открывайте этот порт во внешнюю сеть.

## Что входит в эту итерацию

- Electron desktop-оболочка.
- Запуск локального backend как дочернего процесса.
- Ожидание готовности backend перед открытием окна.
- Сборка React frontend и раздача его backend с того же localhost-origin.
- Изоляция renderer-процесса: `contextIsolation`, `sandbox`, `nodeIntegration: false`.
- Открытие внешних ссылок в системном браузере.
- Хранение новых данных в пользовательской папке, а не внутри установленного приложения.

## Что пока не реализовано

Это не полный клон WaveDM и не production-ready релиз. Пока нет установщика, автообновления, отдельного менеджера browser profiles, миграции старых SQLite-баз, подписания приложения, автоматических тестов интерфейса и полноценного тестирования на Windows. Текущий Chrome Extension оставлен как исходный модуль проекта и не встроен в Electron.

## Новое: Browser Profiles / Accounts Manager

В разделе **Accounts** можно создавать отдельные локальные браузерные профили:

1. Нажмите **Добавить профиль**.
2. Укажите название и при желании Instagram username.
3. Включите индивидуальный прокси и заполните тип, host, port и учётные данные.
4. Нажмите **Проверить соединение**.
5. Сохраните профиль и нажмите **Открыть Instagram**.
6. Войдите в Instagram вручную. Данные сессии сохраняются в отдельном persistent Chromium partition.

У каждого профиля собственная постоянная сессия и собственные настройки прокси. Пароль прокси шифруется средствами защищённого хранилища ОС; он не возвращается в интерфейс при повторном открытии настроек. Чтобы заменить пароль, введите новый. Изменение сетевых настроек закрывает уже открытое окно профиля — откройте его заново.

Удаление профиля удаляет его локальное браузерное хранилище. Перед удалением убедитесь, что вам не нужны сохранённые данные этого профиля.

Профили предназначены для ручного управления аккаунтами. Прокси не гарантирует отсутствие проверок или ограничений Instagram. Не используйте автоматизацию для обхода ограничений платформы.

## Открытие Fingerprint Test в профиле

В разделе Accounts у каждого Browser Profile теперь доступны две отдельные кнопки:
- **Instagram** — открывает https://www.instagram.com/
- **Fingerprint Test** — открывает https://aliasmode.com/ru/fingerprint-test/

Оба окна используют одну и ту же постоянную Chromium-сессию данного профиля и его индивидуальный прокси. Поэтому сайт тестирования видит ту же конфигурацию сетевой сессии и те же браузерные данные профиля. Окна можно открывать независимо; повторное нажатие фокусирует уже открытое окно соответствующего сайта.
